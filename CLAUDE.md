# Working agreement

- Stay within the scope of the current task/prompt only.
- Do not fix unrelated bugs or refactor unrelated code without asking first.
- Work autonomously - don't pause for routine reads/edits/tests, self-correct if something breaks.
- Give progress updates only at major milestones or blockers, not continuously.
- Never commit or push secrets, API keys, or .env files - use .env.example with placeholders.
- Never force-push.
